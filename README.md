# FlowStudio

Небольшой редактор блок-схем на C# и Windows Forms (.NET 8).

## Как запустить

1. Установите Visual Studio 2022 с компонентом «Разработка классических приложений .NET».
2. Откройте файл `FlowStudio.csproj`.
3. Нажмите `F5`.

## Как пользоваться

- Выберите фигуру на верхней панели и щёлкните по белому холсту, чтобы добавить её.
- Выберите «Выбор», чтобы выделить или передвинуть фигуру.
- У выделенной фигуры можно менять размер за квадратные маркеры.
- Чтобы провести стрелку, выберите «Связь», зажмите левую кнопку мыши на первом блоке и отпустите на втором.
- Через «Контур», «Заливка» и список толщины можно менять оформление.
- В меню «Файл» доступны сохранение и загрузка JSON, а также экспорт в PNG и JPG.
- Для удаления выберите фигуру и нажмите `Delete`. `Ctrl+D` создаёт копию.

## Что используется в проекте

- `Models/` — классы фигур и соединительной стрелки.
- `Controls/CanvasPanel.cs` — холст с двойной буферизацией.
- `Enums/ToolMode.cs` — режимы редактора.
- `Serialization/ColorJsonConverter.cs` — сохранение цветов в JSON.
- `MainForm.cs` — интерфейс редактора и обработка действий мыши.
- `examples/client-support-flow.json` — пример блок-схемы.

Фигуры хранятся в `List<Shape>`. Отрисовка выполняется через `Draw()`, проверка попадания — через `ContainsPoint()`. Для сериализации разных фигур используются атрибуты `JsonDerivedType`.
